# Kalshi experimental signal scanner

Deploy on Streamlit Community Cloud with `app.py` as the main file. This prototype uses Kalshi public quotes and Coinbase public one-minute spot candles to display experimental directional momentum. It **does not** fetch the Kalshi target price, use the settlement benchmark, calculate calibrated win probabilities, or establish positive expected value. Do not treat UP/DOWN as a real-money recommendation. No API keys needed.
